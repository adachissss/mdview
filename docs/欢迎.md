# 欢迎使用 mdview

这是一个**只读**的局域网 Markdown 阅读服务，专为平板竖屏/横屏阅读长文档设计。

## 怎么用

把要看的 `.md` 文件复制到：

```
~/project/mdview/docs/
```

- 放在根目录 → 侧栏按文件名列出（悬停看文档标题）
- 放在子目录 → 子目录变成可折叠分组
- **复制后刷新页面即可**，不需要重启服务
- 没放进这个目录的文档，服务完全看不到

## 侧栏与阅读

| 操作 | 效果 |
|---|---|
| ☰ | 收起 / 展开左侧目录（平板上是整栏收起，手机上自动变抽屉） |
| 拖左栏右边缘 | 自由调宽 120–460px，松手停在哪儿就是哪儿；双击恢复 288px；**拖到 120px 以下整栏消失**，点左边缘的 › 弹回 |
| 筛选框 | 按**文件名**边打边筛；按 **回车** 进入全文搜索 |
| 拖正文右边缘 | 调整正文栏宽度（460px 直到铺满内容区），双击把手恢复默认 46rem |
| 排序按钮 | 一排图标：`A↓` 名称A→Z、`A↑` 名称Z→A、🕒↓ 最新在前、🕒↑ 最早在前、☰ 文件最大；点哪个按哪个排，选择会记住 |
| `−` 100% `+` | 正文缩放 60%–200%，按 10% 步进；点百分比回到 100%，自动记忆 |
| 双指捏合 | 在正文上两指张开/捏合直接缩放，松手落档；单指滑动仍是滚动 |
| `⛶` | 进入 / 退出全屏（Esc 也可退出），全屏时右上角有浮动条 |
| `◐` | 深色 / 浅色切换，默认跟随系统 |
| 目录折叠块 | 长文顶部可展开章节导航 |
| 图片 | 点击全屏放大 |
| 代码块 | 右上角「复制」按钮 |

翻到一半关掉页面也没关系：下次会回到同一篇的同一位置。

## 切换文档不刷新

点侧栏、翻页都是**站内切换**，只换右侧正文：

- 全屏状态下连续看多篇也不会被踢出全屏
- 缩放、深浅色、侧栏宽度全部保持
- 每篇的阅读位置单独记忆，切回来接着看
- 浏览器前进 / 后退照常可用（全屏状态下不改地址栏，避免浏览器因此退出全屏）
- **文档被修改后 4 秒内自动重渲染**，完全静默：不弹提示、不闪烁、滚动位置不动；只是保存没改内容时什么都不做

## 关于相对路径图片

Markdown 里写 `![](assets/x.png)` 时，图片必须**和 md 保持相对位置**一起复制过来。例如：

```
docs/
└── 答辩/
    ├── 讲稿.md
    └── assets/
        └── images/
            └── 架构图.png
```

只拷 `讲稿.md` 而丢掉 `assets/`，图片就会显示不出来。

> 想整组搬过来时，直接复制整个文件夹最省事：目录结构和图片引用都能原样保留。

## 看 PDF

`docs/` 里的 `.pdf` 也会出现在侧栏，文件名后面带一个 `PDF` 徽标：

- 点击 → **新标签页**用浏览器自带的 PDF 阅读器打开（平板上是系统阅读器，能翻页、双指缩放、看缩略图）
- 服务端支持 Range 请求，大文件拖动进度条也不会整份重下
- 全文搜索只索引 Markdown，不出现在 PDF 里

当前 `docs/copali` 是软链接进来的，里面的 99 个 PDF 都能直接点开。

## 在网页里添加目录

侧栏底部有个 **「＋ 目录」**，点开可以直接选目录、以软链接加进 `docs/`：

1. 默认从主目录开始，点文件夹进出，也可以在路径框里直接粘贴绝对路径（回车跳转）
2. 下方「链接名」默认取目录名，可以改（不能含 `/`、不能以 `.` 开头）
3. 点「链接到 docs」→ 创建软链接并刷新列表

会拒绝这几种情况：目标不存在/不是目录、docs 下已有同名条目、目标是 docs 自身或其上级（会形成无限递归）。

这是服务端**唯一**的写操作：需要有效令牌，只创建软链接，不复制、不删除任何文件。

## 用软链接挂外部目录

不想复制一份时，直接建软链接：

```bash
ln -s ~/school/software_test/ppt ~/project/mdview/docs/software_test
```

- 服务会跟随软链接，递归列出目标目录里的 `.md`（示例里那 3 篇就是这么来的）
- 文档里相对路径的图片、PDF 也从目标目录读
- 删掉软链接即取消共享，原目录一个字都不会动
- 反过来，链接过去就等于把那个目录也纳入了只读共享范围，别链到敏感目录

## 数学公式

内置 KaTeX（本地打包，不依赖 CDN），支持行内 `$...$` 与独立公式 `$$...$$`：

- 行内：需求分析 $\rightarrow$ 验收测试，系统设计 $\leftrightarrow$ 系统非功能测试
- 下标：$x_i + y_j = z_{ij}$
- 独立公式：

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

代码块和行内代码里的 `$` 不会被当成公式。

## Mermaid 图表

````
```mermaid
graph LR
  A[文档] --> B[渲染]
  B --> C[平板]
```
````

用 ` ```mermaid ` 代码块即可，流程图、时序图、类图、状态图、甘特图都支持；深色模式下会跟着换成深色主题。

- 图表**默认撑满正文栏宽**（不再是缩在中间的一小块）
- 每张图右上角有 `− 100% +`，可以**单独**缩放这张图（40%–250%），点百分比恢复 100%；比例按「文档 + 第几张图」记住，刷新也不丢
- 3.5MB 的 mermaid 库是**按需加载**的——文档里没有图就不会下载

## 安全边界

- 服务**只读**，没有任何上传或写入接口
- 只暴露 `docs/` 一个目录，路径穿越和符号链接逃逸都会被拒绝
- 默认用 URL 令牌访问（`?k=...`），同一网段的人猜不到
- 不适合放到公网：它是给家里的 Wi-Fi / 校园网局域网用的
